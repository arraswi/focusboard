# Focusboard

Um painel pessoal de tarefas feito para organizar o dia sem complicação. Os dados ficam salvos no navegador, sem conta e sem backend.

## Recursos

- Criar, concluir e excluir tarefas.
- Categorias e prioridades.
- Filtros para todas, pendentes e concluídas.
- Resumo de progresso atualizado automaticamente.
- Persistência no navegador com localStorage.
- Layout adaptado para celular e desktop.

## Executar localmente

Requisitos: Node.js 20.19 ou superior.

    npm install
    npm run dev

Abra o endereço local mostrado pelo Vite no terminal.

## Tecnologias

React · TypeScript · Vite · CSS
